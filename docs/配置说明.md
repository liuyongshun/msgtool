**配置文件**: `config/sources.json`  
**最后更新**: 2026-02-26
**新增功能**: 
- 翻译配置开关（所有数据源独立控制）

```json
{
  "sources": {
    "news": { ... },      // 新闻源配置
    "rss": { ... },       // RSS 源配置
    "github": { ... },    // GitHub 源配置

}
```

## 🔧 全局配置 (global_settings)

### 基础设置

```json
{
  "default_cache_ttl": 300,           // 默认缓存时间（秒）
  "default_fetch_limit": 10,          // 默认抓取数量
  "max_fetch_limit": 50,              // 最大抓取数量
  "request_timeout": 30,              // 请求超时时间（秒）
  "user_agent": "Mozilla/5.0 ..."    // HTTP 请求 User-Agent
}
```

### 维护配置 (maintenance)

```json
{
  "maintenance": {
    "log_retention_days": 7,          // 日志保留天数
    "cache_retention_days": 30,       // 缓存保留天数
    "auto_cleanup": {
      "enabled": true,                // 启用自动清理
      "log_cleanup_time": "03:00",    // 日志清理时间（每天）
      "cache_cleanup_time": "02:00",  // 缓存清理时间
      "cache_cleanup_day": "sunday"   // 缓存清理日期（每周）
    }
  }
}
```

**说明**:
- `log_retention_days`: 保留最近N天的日志文件
- `cache_retention_days`: 保留最近N天的缓存文件
- `auto_cleanup.enabled`: 启用后，调度器会自动执行清理任务

### 调度器配置 (scheduler)

```json
{
  "scheduler": {
    "enabled": true,                  // 全局开关
    "tasks": {
      "arxiv": {
        "enabled": true,              // arXiv 任务开关
        "time": "09:00",              // 执行时间
        "max_results": 20,            // 每个分类最多抓取论文数
        "translation_strategy": {
          "enabled": true,
          "selective_translation": true,  // 选择性翻译
          "min_authors": 2                // 最小作者数阈值
        }
      },
      "hackernews": {
        "enabled": true,
        "time": "10:00",
        "max_results": 50
      },
      "rss": {
        "enabled": true,
        "time": ["06:00", "08:00", ..., "22:00"],  // 多个时间点
        "max_results": 20
      },
      "github": {
        "enabled": true,
        "time": "14:00",
        "max_results": 100
      }
    }
  }
}
```

**说明**:
- `enabled`: 全局开关，关闭后所有任务都不执行
- `tasks.*.enabled`: 单个任务开关
- `tasks.*.time`: 执行时间（24小时制），支持字符串或数组
- `tasks.*.max_results`: 控制抓取数量

## 🤖 AI 模型配置 (llm)

```json
{
  "llm": {
    "enabled": true,                            // 启用 AI 功能
    "provider": "deepseek",                     // 提供商
    "api_key": "sk-xxxxxxxxxx",                 // API 密钥
    "api_url": "https://api.deepseek.com/v1/chat/completions",
    "model_name": "deepseek-chat",              // 模型名称
    "max_tokens": 1000,                         // 最大 token 数
    "temperature": 0.3,                         // 温度参数
    "recent_days": 1                             // 时间过滤：仅处理最近 N 天内的数据
  }
}
```

**参数说明**:
- `enabled`: 启用后才会进行 AI 筛选和翻译
- `api_key`: DeepSeek API 密钥（获取地址：https://platform.deepseek.com/）
- `max_tokens`: 控制 AI 响应长度
- `temperature`: 控制 AI 输出随机性（0.0-1.0，越低越确定）
- `recent_days`: **时间过滤参数**
  - 仅对 HackerNews、RSS、arXiv 生效
  - 在调用 LLM（AI筛选/翻译）前，先过滤掉超过 N 天的旧数据
  - 可有效减少不必要的 Token 消耗
  - **建议值**：
    - 定时任务（每天自动运行）：设为 `1`，只处理当天数据，避免重复
    - 按需触发（手动/技能调用）：设为 `7`，覆盖近一周数据，防止遗漏

**Token 优化建议**:
- arXiv 选择性翻译可节省 76% token
- GitHub 白名单缓存可节省 70-85% token
- **时间过滤**（`recent_days`）可节省 30-50% token（取决于数据源更新频率）

## 📰 数据源配置

### 1. HackerNews 配置

**配置位置**: `sources.news.hackernews`

```json
{
  "enabled": true,
  "name": "Hacker News",
  "type": "api",
  "api_base_url": "https://hacker-news.firebaseio.com/v0",
  "story_types": ["top", "new", "best"],       // 新闻类型
  "ai_filter_enabled": true,                   // 启用 AI 筛选
  "translation_enabled": true,                 // 启用文章翻译（新增）
  "fetch_limit": {
    "default": 10,
    "max": 50
  }
}
```

**配置项说明**:
- `translation_enabled`: 控制是否启用文章翻译（默认 `true`，设为 `false` 可节省 Token）
- `ai_filter_enabled`: 启用 AI 筛选，仅保留 AI 相关文章

**story_types 说明**:
- `top`: 热门新闻
- `new`: 最新新闻
- `best`: 高分新闻

### 2. RSS 源配置

**配置位置**: `sources.rss.*`

**单个 RSS 源示例**:
```json
{
  "mit_tech_review": {
    "enabled": true,                          // 是否启用
    "name": "MIT Technology Review AI",       // 显示名称
    "url": "https://www.technologyreview.com/feed/",  // RSS URL
    "description": "MIT科技评论AI频道",        // 描述
    "category": "technology_news",            // 分类
    "tags": ["AI资讯", "技术博客"],            // 标签
    "ai_filter_enabled": true,                // 是否启用 AI 筛选
    "translation_enabled": true               // 启用文章翻译（新增）
  }
}
```

**配置项说明**:
- `translation_enabled`: 控制是否启用文章翻译（默认 `true`）
- `ai_filter_enabled`: 启用 AI 筛选，仅保留 AI 相关文章

**category 类别**:
- `technology_news`: 科技新闻
- `company_blog`: 公司博客
- `personal_blog`: 个人博客
- `newsletter`: 邮件通讯
- `tech_community`: 技术社区
- `ai_tools`: AI 工具
- `papers`: 论文
- `trends`: 趋势分析
- `engineering`: 工程实践
- `news`: 新闻媒体

**RSS 源状态说明**:
- 当前配置中部分 RSS 源可能因网络、URL 变更等原因出现 404/连接失败
- 建议定期检查 `output/daily/YYYY-MM-DD/rss_*.json` 中的 `errors` 字段
- 对于长期失败的源，建议在配置中设置 `enabled: false` 以节省抓取时间
- 部分源使用 `localhost:8878`（RSSHub 本地实例），需确保 RSSHub 服务运行

**tags 标签**:
- `AI资讯`: 通用 AI 新闻
- `AI工具`: AI 工具和产品
- `AI论文`: 学术论文
- `技术博客`: 技术深度内容
- `趋势分析`: 行业趋势

### 3. GitHub 配置

**配置位置**: `sources.github.trending_daily`

```json
{
  "enabled": true,
  "languages": ["python", "javascript", "typescript", "rust"],
  "trending_types": ["created"],
  "created_days": 15,
  "star_limits": {
    "pushed": 500,                             // pushed 类型最小 star 数
    "created": 300,                            // created 类型最小 star 数
    "stars": 500                               // stars 类型最小 star 数
  },
  "ai_filter_enabled": true,                   // 启用 AI 筛选
  "translation_enabled": true,                 // 启用项目翻译
  "database_enabled": true                     // 启用 GitHub 数据库功能
}
```

**配置项说明**:
- `translation_enabled`: 控制是否启用项目描述翻译（默认 `true`）
- `ai_filter_enabled`: 启用 AI 筛选，仅保留 AI 相关项目（关闭后直接返回所有满足条件的仓库）
- `database_enabled`: 启用 GitHub 数据库功能（默认 `true`），实现智能去重和持久化存储

**trending_types 说明**:
- `pushed`: 最近7天有推送的项目
- `created`: 最近 `created_days` 天内新建的项目（推荐，目前默认使用此类型）
- `stars`: 最近180天创建的高 star 项目

**`created_days` 说明**:
- 仅对 `created` 类型生效，控制查询"最近多少天内创建"的项目
- 默认 `15` 天，可适当调大（如 `30`）以获取更多候选项目

> **注意**：GitHub 查询策略已改为纯按语言 + star数 + 创建时间过滤，不再使用关键词限制，AI 相关性由 LLM 判断。

**语言支持**:
- `python`
- `javascript`
- `typescript`
- `rust`

## ⚙️ Token 优化配置

### 1. 时间过滤（`llm.recent_days`）

仅处理最近 N 天内的数据，节省 30-50% Token：

```json
{
  "llm": {
    "recent_days": 1    // 定时任务推荐：1（仅当天）；按需触发推荐：7（近一周）
  }
}
```

### 2. arXiv 选择性翻译

只翻译多作者论文，节省 76% Token：

```json
{
  "scheduler": {
    "tasks": {
      "arxiv": {
        "translation_strategy": {
          "selective_translation": true,
          "min_authors": 2
        }
      }
    }
  }
}
```

### 3. GitHub 白名单缓存

自动启用，无需配置。已筛选的 AI 项目缓存 30 天，节省 70-85% Token。

### 4. 翻译开关优化

根据内容类型禁用不必要的翻译：

```json
{
  "translation_enabled": false    // 英文技术博客可禁用
}
```

**建议**:
- ✅ 始终启用：arXiv 论文、GitHub 项目
- ⚠️ 可选启用：英文技术博客
- ❌ 建议禁用：中文内容

### 5. max_results 参数说明

| 数据源 | 含义 | AI筛选 | 输出策略 |
|--------|------|--------|---------|
| arXiv | 每个分类最多抓取论文数 | ❌ | 全部保存 |
| HackerNews | 原始数据抓取上限 | ✅ | AI筛选后全部保存 |
| RSS | 每个源最多抓取条目数 | ✅ | AI筛选后全部保存 |
| GitHub | 每种查询类型抓取上限 | ✅ | AI筛选后全部保存 |

**重要**: `max_results` 只控制原始数据量，AI 筛选后的所有结果都会保存。

## 🔒 安全配置

### API 密钥管理

**⚠️ 重要**:
1. 不要将包含真实 API 密钥的配置文件提交到公开仓库
2. 使用 `.gitignore` 保护配置文件
3. 定期更换 API 密钥

### 访问控制

**预览服务** 默认绑定到 `localhost:5001`，仅本地访问。

如需外网访问，需修改 `src/preview_server.py`：
```python
app.run(host='0.0.0.0', port=5001)  # 允许外网访问（慎用）
```
